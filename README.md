<h3 align="center">👨🏼‍💻 P O R T F Ó L I O 💼</h3>

--------------------------------------------------

<p> Este repositório contém o código-fonte do meu portfólio pessoal, onde compartilho meus projetos, experiências e habilidades profissionais.
  O objetivo deste portfólio é demonstrar minha evolução como desenvolvedor(a) e facilitar o acesso ao meu trabalho para possíveis colaboradores ou empregadores. </p>

--------------------------------------------------

<h3>🔍 O que você vai encontrar aqui</h3>

- Página inicial: Breve introdução sobre mim, com links para minhas redes sociais.
- Projetos: Uma seção dedicada aos principais projetos em que trabalhei, com links para o código ou demonstrações.
- Experiência e habilidades: Uma lista das minhas principais competências técnicas e experiências profissionais relevantes.
- Contato: Informações sobre como me contatar para oportunidades e colaborações.

--------------------------------------------------

<h3>🚀 Tecnologias Utilizadas</h3>

- [HTML](https://www.w3schools.com/html/): Utilizado para estruturar as páginas do projeto no caso a versão do site em português (pt-br) e outra em inglês, permitindo a navegação em múltiplos idiomas. 
  
- [CSS](https://www.w3schools.com/css/): Utilizado para estilizar e customizar a aparência do site. Também foi utilizado para criar animações, garantindo uma experiência visual mais agradável e interativa.
  
- [JavaScript](https://www.w3schools.com/js/DEFAULT.asp): Responsável por adicionar interatividade e alguns elementos visuais dinâmicos. Por exemplo, foi utilizado para implementar partículas na interface.
